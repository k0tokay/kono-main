name: placement-triage
description: 辞書の語に配置の状態（配置／暫定配置／未配置）を付ける．既存の?タグの振り分け，新語登録時の状態付け，未配置から配置への格上げの審査に使う．「配置の状態を付けて」「?タグを振り分けて」「未配置にして」で使う．
argument-hint: <対象（語ID列，タグ名，部分木の根）>
allowed-tools: Read, Grep, Glob, Write, Bash(npm run --silent dict -- *), Bash(python3 *), Bash(.claude/scripts/formal-check.sh*)

## 入力
- $ARGUMENTS：対象の語．ID列，タグ（例 `?`），または部分木の根．
- 規範：`detail/chapters/s-side/upper-classification.tex` の分類作法「配置の状態」と完了条件．辞書章の tags 規約．

## 禁止事項
- 辞書JSONを直接書かない．`npm run --silent dict -- apply` のパッチで書く．
- 本文にない分割を根拠に「配置」にしない．辞書だけにある節点（本文に現れない中間節点）の兄弟排他は根拠にならない．
- 迷ったら配置にしない．未配置→配置は保存拡大で後からできるが，逆は帰結の撤回になる．
- 確信のない上位への被覆を「状態が未配置だから」と残さない．状態は分割の主張を弱めるだけで，被覆（包摂）は確かでなければならない．
- 上位節点の誤り（親の被覆・廃止候補の節点）を対象語の作業で直さない．報告に回す．
- 未配置の語を集める擬似節点を作らない（却下録）．「その他」「不明瞭な〜」型の既存節点は擬似節点の候補として報告する．

## 手順
1. 対象語ごとに祖先の鎖，兄弟，子を取る（辞書CLIの search/context，または JSON を読むスクリプト）．
2. 鎖の各節点が本文に現れるかを grep し，本文にある分割（骨格枝・素性の値・外延的に与えた分割）を特定する．`\iffalse` 内は本文でない（`.claude/scripts/active-lines.py` で確認）．
3. 語ごとに二段で判定する．
   - (a) 被覆：直上への包摂は確かか．本文と矛盾するなら本文の節点へ移す．多義で確かでないなら，諸語義に共通する最も深い節点へ上げる．
   - (b) 状態：本文にある分割に参加し，かつ根拠（その分類を使う推論／話者に強いる区別／表現の選び分け）を言えるなら配置．配置と同じ主張だが語義分割や移行が予定されているなら暫定配置．それ以外は未配置．
4. 判定表を日付ログに書く（語，被覆の変更，状態，根拠，付記：語義分割候補・格上げ候補・親の問題）．
5. パッチを作り，`apply`（dry-run）→ `apply --write`．tags の `?` は外し，状態タグを付ける（配置はタグなし）．
6. 辞書章の todo や本文の「暫定配置」の用法に波及があれば更新し，形式検査を通す．
7. 報告：状態ごとの語数，被覆を動かした語，作者に諮る方針の問い（根に触れるもの），親の問題の一覧．

## チェックリスト
- [ ] 配置にした語すべてに，本文の分割箇所と三つの根拠のどれかを書いた．
- [ ] 被覆を動かした語すべてに，本文の根拠か多義の理由を書いた．
- [ ] 親の問題は直さず報告に回した．
- [ ] パッチ適用後に `validate` が通った．
