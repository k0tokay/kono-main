一次分類を\ko{matonakt}を原子とする帰納的構成で定める．
\begin{itemize}
  \item \ko{matonakt}：材料量．メレオロジー的外延性を持つ．
  \begin{itemize}
    \item \emph{例}：（ある量の）鉄，水，血，砂．
  \end{itemize}
  \item \ko{klant}：構成員による外延的な構成．
  \begin{itemize}
    \item \emph{例}：紙束の紙，森の樹木，カゴの中の果物，動物の群れ，電車から降りる人達の外延的な集まり．
  \end{itemize}
  \item \ko{takto}：配置・機能・制度・履歴等の付加による構成．
  \begin{itemize}
    \item \emph{例}：心臓，人，机，石，本，山．
  \end{itemize}
\end{itemize}
\ko{klant}と\ko{takto}を\ko{noflem}としてまとめる．この三場合は，生起物の単純・集成・文脈的複合という構成に概ね対応するが，同一性の様式まで一致するわけではない．
\begin{remark}
統一性（unity）は補助的な検査とする．一様な成員のまとまりは\ko{klant}，配置・機能等によるまとまりは\ko{takto}の典型に対応するが，外延的な集まりにunityがあるとは限らず，\ko{noflem}の定義条件にはしない．
\end{remark}
\begin{whynot}
dissectivity（クラスに属する個体の部分がまたそのクラスに属するか）は，クラスに対するメタ性質であり，個体の分類には使えない．例えば「1杯の紅茶」とみなせるある概念を考えたとき，「1杯の紅茶」に属すると考えればnon-dissective，「紅茶」としてはdissective，「紅茶または人」としてはnon-dissective，「全てのもの」としてはdissectiveとなり，概念に対してはdissectivityが定まらないという問題がある．
%「紅茶」（材料量）と「1杯の紅茶」（分量・容器で個体化された量）は同一性基準が異なる別個体であり，同じ個体の二側面ではなく見做しグラフで結ぶ（「見做しグラフと語義分割」節．2026-09-07）．同じ船たちの外延的な集まりは\ko{klant}，艦隊組織はその集まりへの見做しを持つ\ko{takto}である．
\end{whynot}

\subsection{材料量：matonakt}
% \ko{matonakt}は和である．旧稿の基準「物理的部分の位置関係に依存するか」は採らない（2026-09-03）．
\rele{hanov}{matonakt}{matonakt}{部分性関係，部分-全体関係，$x_1$は$x_2$の物理的部分である}
\ko{hanov}は\ko{matonakt}上の部分関係で，公理系はGEM（半順序，強補充，非空集合の和の存在．DOLCEが抽象物と生起物に採る非時間的部分関係の公理系 \citet{masolo-etal2003} Ad5--Ad9）を材料量に採る．同じ部分を持つ材料量は同一である．散在する材料量の和も材料量である．
\rele{manov}{matonakt}{noflem}{材料関係，$x_1$は$x_2$の全材料量である}
\ko{manov}は\ko{noflem}の各個体に，同じ時期のその全材料量を一意に対応させる（時間変化は\ko{manov}のハブの時制で扱う．設計規範「時制は開ハブで表す」）．\ko{hanov}は\ko{nato}上ではなく\ko{matonakt}上の関係なので，\ko{noflem}の個体，例えば\kotr{coto}{人}，\kotr{kina}{手}の物理的部分について\ko{kina hanov coto}と書くのは，両者の材料量の間の\ko{hanov}の換喩的省略である．
\begin{example}
砂山の形をしたある量の砂がある．その砂山を崩して砂を散り散りにしたとすると，砂山としての同一性は維持されなくなるが，ある量の砂としての同一性は維持される．砂山は\ko{takto}（同一性プロファイルは形態と地理的位置），ある量の砂は\ko{matonakt}である．
\end{example}
\subsection{集合体：klant}
\rele{hanem}{nato}{klant}{構成員関係，構成員-集合体関係，$x_1$は$x_2$の構成員である}
\ko{hanem}は推移しない．同じ構成員を持つ集合体は同一であり，構成員が替われば別個体となる．
空の集合体，構成員一つの集合体は認めない．
\begin{remark}
    不純集合は\ko{loka}の形式構築物に置き，集合体と語彙を分ける．\ko{hanem}は構成員から派生的位置を与えるが，不純集合の所属関係\ko{litoi}は与えないことによって，集合体を具体物，不純集合を抽象物とする．この選択の非恣意的な根拠は\emph{未決}である．
\end{remark}
% \memo{森などの下位語について，外延的な集まりと存続する個体の語義分割・見做しの辞書整備が残る．}
同じ人からなる委員会とサークルは，同じ\ko{klant}への見做しを持つ別の\ko{takto}である．\ko{klant}は語彙的に空とし，\ko{takto}からの見做しや構成員からの構成$+\ko{kla}$によって到達する．
\subsection{オブジェクト：takto}
\ko{takto}は，材料量や集合体などに文脈を付加して構成する開ハブである．成分が同じでも文脈によって別個体となりうる．何を成分とし，どの配置・機能・制度・履歴等を要するかを各語義で指定し，計数・存続条件を同一性プロファイルとして与える．文脈は同一性を一意に決めるタプル成分ではない．

\section{matonaktの中位分類：材料モジュール}
\ko{matonakt}には独立の内容語彙を置かない．内容語彙は材料量を分類する\emph{種}（概念個体）の側に置き，個々の量へは指示・量化・\ko{manov}による到達を使う（上位分類の章「操作によって到達する分類」）．種を与えても「その種の量」は一意に選ばれず，任意の部分・融合について種への該当が保存されるともしない（粉体，コロイド）．2026-09-15採択，暫定．

種は\emph{何に適用するか}で三つに分ける．
\begin{itemize}
  \item 個体に適用する種：粒子・原子・分子（\kox{電子}，\kox{原子}，\kox{分子}，\kox{高分子}〔一分子〕）．量子的な個体を\ko{nato}のどこに置くかは未決．
  \item 材料量に適用する種：\kotr{kisa}{水}，\kotr{hoft}{空気}，\kotr{tonnolk}{鉄}，\kox{混合物}，\kox{固体}など．
  \item 種を分類する概念：\kox{元素}（原子種を原子番号で分類する）．鉄の塊が元素という概念個体になるのではない．
\end{itemize}
粒子$\to$原子$\to$分子$\to$物質を一本のis-a鎖にしない．\kox{高分子}〔一分子〕と\kox{高分子物質}，DNA分子とDNA材料のような対は，種の包含ではなく\emph{成分}関係で結ぶ．

材料量に適用する種の中位分類は，次の交差する分類基準で行う．排他的な一次分類ではなく，一項目が複数の基準を満たしてよい．
\begin{itemize}
  \item 化学組成・主成分：\kox{純物質}（\kox{単体}，\kox{化合物}）／\kox{混合物}（\kox{溶液}，\ko{hoft}）．判定は語義で指定した成分水準で行い，量の部分を数えて判定しない（NaClのNaとClを数えて混合物としない）．
  \item 内部秩序・組織・分散形態：\kox{結晶質}／\kox{非晶質}（\kotr{kelen}{ガラス}），\kox{コロイド}（\kox{懸濁液}，\kox{乳濁液}，\kotr{hotalje}{煙}），\kox{粉体}（\kotr{hasnu}{砂}，\kotr{tsagus}{砂利}），繊維状（\kotr{halmof}{綿}，\kotr{kohak}{紙}）．
  \item 相・状態：\kox{固体}，\kox{液体}，\kox{気体}，\kox{プラズマ}．ある量がある相に該当することは条件に依存するので，量と種を参加者とする時制可能な開ハブで表す．\ko{kisa}という種と\kox{液体}という種は交差であって同一視しない．
  \item 電子的性質・機構：\kotr{tsonem}{金属}〔金属状態の材料〕，\kox{半導体}，\kox{絶縁体}（\kox{Mott絶縁体}）．金属元素という分類とは区別する．
  \item 由来・生成過程：\kotr{kasov}{木材}，\kotr{magnom}{牛乳}，\kotr{ynoli}{血}，\kotr{tcai}{茶}．同じ組成・組織でも由来が違えば名称が外れる種．
  \item 加工材料：\kox{合金}，\kox{セラミックス}，\kox{プラスチック}，\kox{複合材料}．工学的な整理の観点であり，人工的加工を必要条件としない．
\end{itemize}
\begin{whynot}
材料量を単純／複合の排他的な二枝に分ける案は採らない．水の量を二分して融合しても同じ量に戻るので，和の履歴では個体を分類できず，「材料種に一つでも所属すれば単純」は上位種や新しい混合物名で自明化する．混合物・複合材料の区別が要るなら種側の組成・組織の条件として書く（2026-09-15）．
\end{whynot}
候補表と各項目の境界は\texttt{2026-09-15/material-kind-vocabulary.md}．既存語（\ko{kisa}が氷を含むか，\ko{tcai}が茶葉を指せるか等）の語義確認と辞書の移行は未実施．

\section{taktoの中位分類}
\ko{takto}の下に骨格枝は切らない．\ko{takto}の全語義は同じ射影署名を持つので，中位分類はすべて交差を許す素性クラスであり，次の二軸に分ける（2026-09-15採択，暫定）．
\begin{itemize}
  \item \emph{個体化の根拠}（統一源泉）：時点を固定して「なぜ一つの塊か」を与える統合関係$R$の型（上位分類の章「統一性」）．各語義は一つ以上を宣言する（主統一と副統一）．統合関係そのものはメタ言語に留め，型の名だけを語にする．
  \item \emph{横断する分類}：統一源泉と交差して語彙化するクラス．種の木，由来，能力，部分としての地位，領域．
\end{itemize}
同一性プロファイル（通時の存続条件）は語義ごとの宣言のままとし，節点にしない．統一源泉と同一性プロファイルは相関するが一致しない：壊れた時計は機能複合の統一を保ちつつ機能を失い，侵食された山は形態の統一を保ちつつ形を変える．
\begin{whynot}
YAMATOの「機能を失えば同一性を失う機能物」「形を失えば同一性を失う形態的全体物」を\ko{takto}の排他的な下位枝とする案は採らない（2026-09-02）．却下したのは排他枝と通時的な読みであり，共時の統一関係としての機能・形態は統一源泉に残す．
\end{whynot}

\subsection{個体化の根拠：統一源泉}
七つを閉じた目録とする．新しい型の追加には新装置と同じ立証責任を課す．どれも満たさない候補は\ko{takto}に置かない．
\begin{itemize}
  \item \kox{結合}：物理的束縛（化学結合・固体凝集・重力）のもとで結合かつ閉包．判定：同種の連続体へ延長できれば閉包失敗（山は地殻と連続，恒星は分離）．例：恒星，惑星，岩石，水滴．
  \item \kox{形態}：形態・位相条件（突出，盆地，輪郭）が成員指定と独立に切り出す．判定：結合閉包は失敗するが計数できる．境界は多くfiat．例：山，丘，島，砂山，森〔領域〕．
  \item \kox{機能複合}：分化した部分が異なる役割を担い，その役割関係が$R$．判定：役割を入れ替えると全体の能力が壊れる．後付けの用途（文鎮にした石）では否．例：ハンマー，時計，建物，車，心臓．
  \item \kox{自己維持}：境界と体制を自ら維持する閉包（代謝・恒常・修復）が$R$．判定：維持が止まると残るのは死体側の結合・形態．例：\ko{halov}の全語義．
  \item \kox{過程担体}：特徴的な\ko{astav}を担うチャネルとして切り出す．判定：過程が止まっても残る持続体がある．例：川（河道／水／流れの見做しグラフの対象側），氷河．
  \item \kox{制度}：構成的規則（設立・承継・地位の割り当て）が$R$．判定：同じ構成員でも制度が違えば別個体．例：会社，国家，委員会．
  \item \kox{fiat分割}：物理的不連続なしに規約だけが閉包を与える．判定：境界を横断する結合・形態が分割と無相関．例：領土，北半球．
\end{itemize}
\ko{takto}に置かないもの：水・砂・空気（\ko{matonakt}），群れ・国民（\ko{klant}．語彙的に空），炎・渦・嵐・海流（\ko{astav}．境界例として攻撃工程に残す），穴・部屋（空隙），雲（材料量＋過程）．

\subsection{横断する分類}
\begin{itemize}
  \item 種の木：\ko{halov}（生物）を根とし，統一源泉は自己維持．剛．各世界における種から\ko{halov}への包摂はその世界の種分類データとして与え，ある種の語義が生物であることを定義条件に含む場合だけ共通公理として維持する（2026-09-06）．\ko{bafnol}（動物），\kox{植物}，\kox{菌類}，\ko{cotel}（ヒト．全世界で\ko{cotel}$\subseteq$\ko{halov}）はこの木の節点．
  \item \ko{coto}（人）：その世界で人と呼ばれるもの．剛．所属は\ko{halov}と同じく世界ごとのデータで，現実世界では\ko{cotel}と外延が一致し，虚構世界では人型の登場人物を含む．ロボットと法人は含まない．人称代名詞はこれに基づく．\ko{kaeno}と独立（昏睡中の人は\ko{coto}だが\ko{kaeno}でなく，ロボットは\ko{kaeno}だが\ko{coto}でない）．2026-09-15裁定（09-14裁定を精密化）．
  \item \ko{kines}（人工物）：由来による．$\exists s\,[\,s\in\ko{kynoy}\land x\ \ko{me}\ s\land \exists A\,(A\ \ko{ja}\ s)\,]$（意図的な創造行為の被創造物）．創成済みの個物について剛．
  \item \ko{kaeno}（エージェント）：能力による．$x$が意図傾向タイプに属する個別傾向$d$を担う（$\mathrm{bear}(x,d)$．量・性質モジュールの章）とき，かつそのときに限る．能力を失っても同一個体なので剛でない．生物・ロボット・制度的組織と交差し，\ko{halov}との交差に名を与えない（サンゴは\ko{bafnol}だが\ko{kaeno}でない）．
  \item \ko{halonant}（器官）：部分としての地位による．機能複合の統一を持ち，宿主が\ko{halov}であるもの．材料量が宿主の材料量の\ko{hanov}部分であることは整合制約であって十分条件ではない（任意の肉片は器官でない）．摘出後は宿主接続が切れるので剛でない．例：心臓，手，葉．
  \item 領域クラス（統一源泉と同一性プロファイルからの定義）：
    \begin{itemize}
      \item \kotr{fleneko}{天体}：結合かつ束縛系＋軌道履歴かつ非\ko{halov}．
      \item \kox{地理的対象}：位置と境界の履歴を必須とし，主統一が形態・過程担体・fiat分割のいずれかで，機能複合でも自己維持でもない．山・川・領土は入り，建物・橋・道路は入らない（主統一が機能複合）．
      \item \kox{建造物}：\ko{kines}かつ機能複合かつ設置位置の履歴を含み，移動を存続条件にしない．
      \item \kotr{laitces}{乗り物}：\ko{kines}かつ機能複合かつ移動機能が種差．
      \item \kotr{folkana}{容器}：機能複合かつ内腔保持の役割分担．
      \item \kox{制度的組織}：主統一が制度．
    \end{itemize}
\end{itemize}
\ko{kinano}（機能傾向の担い手）は立てない．機能複合があれば残る用途は後付けの用途だけで，同一性プロファイルの機能とも別である．旧\ko{konkaeno}／\ko{calfkaeno}は\ko{klant}への見做しの有無として読む．交差に名を与えない：\ko{kaeno}$\cap$\ko{halov}，\ko{coto}$\cap$\ko{cotel}，\ko{kaeno}$\cap$\kox{制度的組織}．
\begin{example}
  \begin{enumerate}
    \item ハンマー：機能複合（主統一）；プロファイルは機能＋形態；\ko{kines}．
    \item 山：形態；位置＋境界履歴＋形態；\kox{地理的対象}．
    \item 恒星：結合；束縛系の連続（質量放出を許す）；\ko{fleneko}．形態も機能も同一性の主条件にしない．
    \item 会社：制度；制度的継承；\kox{制度的組織}，しばしば\ko{kaeno}；構成員の\ko{klant}へ見做し．
    \item 猫：自己維持；生命的連続性；\ko{halov}，\ko{bafnol}，しばしば\ko{kaeno}．
  \end{enumerate}
\end{example}
見做しは木の辺にしない：川—河道—水—流れ，国家—領土—国民（\ko{klant}），森—樹木の\ko{klant}，会社—構成員の\ko{klant}，本〔冊子〕—内容（\ko{kika}），像—粘土（\ko{matonakt}）．
\memo{制度的対象と\ko{manov}：社員ゼロの会社は位置を持たない．\ko{manov}を物理的な\ko{noflem}の上でだけ全域とし，制度的\ko{takto}の位置は構成員\ko{klant}・所在地からの派生的位置とする案．\ko{nato}が位置を要求するかは根の問い（DOLCEは社会的対象を非物理的持続物に分ける）．}
\memo{生物の剛性と死体：死後の身体を同じ個体とするかは未裁定．統一源泉と同一性プロファイルの独立性（自己維持が生命的連続性を含意するか），Guarino--Weltyの統一の型とBFOの因果的統一の種類の原典確認も残る．語彙候補と表は\texttt{2026-09-15/takto-middle-classification.md}，検討経緯は\texttt{2026-09-15/tenbin001}．}

\subsection{見做しグラフと語義分割}
一語が異なる同一性基準を持つ個体を規則的に指す場合，それらを同一個体の交差とはせず，有限個の存在論的節点と型付き二項関係の連結グラフ，および各節点を同じ語形で呼ぶという語彙化決定からなる\emph{見做しグラフ}で結ぶ（上位分類の章の見做し目録の一般化．従来の二側面の見做しは節点数が二の場合）．特定の三項組を二項関係から復元できない反例が確認された場合に限り，三成分への射影を持つ閉じた束ハブを導入する．
\begin{example}
  \begin{enumerate}
    \item 川：河道（地理的\ko{takto}）／水（\ko{matonakt}）／流れ（\ko{astav}）．主側面を先に固定しない．
    \item 国：制度的組織（\ko{takto}，制度的継承）／領土（地理的\ko{takto}）／国民（\ko{klant}）．
    \item 森：樹木の集まり（\ko{klant}）／森林領域（地理的\ko{takto}）．
    \item 一杯の紅茶：容器（\ko{takto}）／紅茶（\ko{matonakt}）．
  \end{enumerate}
\end{example}
一つの語義概念には一つの辞書IDを与える．同じ語形が複数概念を見做しで結ぶ場合も概念IDは分け，共通語形と見做し目録から各語義への対応を別に記録する（紙・骨・卵・お金・木材は語義分割の対象）．
\begin{example}[一語が複数の節点に対応する語]
  \begin{enumerate}
    \item お化け：現実世界の持続物種として一律には置かない．キャラクター役（\ko{kika}），作品世界内の対応者，信念の内容（\ko{klaleme}），知覚経験（\ko{astav}）に語義を分ける．現実存在を仮定した世界内個体だけが\ko{takto}になりうる．
    \item 音：音トークンは原則\ko{astav}．音源は別の\ko{nato}個体，音質は\ko{canon}，反復可能な音形は表現形態．「音」を共通の\ko{nato}節点として立てない．
  \end{enumerate}
\end{example}
